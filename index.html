What is the 8-Puzzle Problem?

The 8-puzzle is a sliding-tile puzzle on a 3×3 grid. Eight tiles are numbered 1–8 and one cell is empty (the blank). A tile next to the blank can slide into it, which is the same as moving the blank up, down, left or right. The aim is to turn a given initial state into a given goal state using legal slides.

Because the puzzle is a classic state-space search problem, it is perfect for studying AI search:

  • State: one arrangement of the nine cells (there are 9! = 362,880, but only half of them, 181,440, are reachable from any given state).
  • Initial / goal state: the arrangement we start from and the one we want.
  • Actions: Up, Down, Left, Right (movement of the blank, when it stays on the board).
  • Transition & cost: each action produces a new state at a step cost of 1, so path cost = number of moves.
  • Goal test: does the current arrangement equal the goal arrangement?

Not every pair of arrangements is connected. Exactly half of all permutations can reach a given goal; the solver checks the inversion parity of your puzzle first and tells you straight away if a puzzle is impossible.

About Depth Limited Search

DLS is Depth-First Search with a ceiling. It follows one branch as deep as it is allowed (the depth limit l), treats nodes at depth l as dead ends, then backtracks and tries the next branch. The limit fixes DFS's classic weakness (wandering down an endless path) but introduces a new one: if the goal lies deeper than l, DLS reports a cutoff instead of a solution.
